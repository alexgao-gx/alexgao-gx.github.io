03AI-powered UX

Trust is an interaction pattern, not a badge

The panel answers questions about this portfolio. It is a deterministic demo — no model is called — built to the conventions a Copilot-style feature needs: it streams, it can be stopped, it cites sources you can click, it says when it has none, and it labels itself.

Grounding, not a percentage
People can act on "grounded in 2 sections" or "no source on this page"; they can't act on "confidence 71%". Shipped as confidence and explainability indicators at eBay; carried into the Apple search experience.
Refusal is a state
When the answer has no source, the panel says so and offers a next step — the same fallback logic the Apple components handle for partial and failed responses.
Streaming with a way out
Progressive rendering keeps the UI responsive under model latency; Send becomes Stop while generating; the transcript is not a live region, so the answer is announced once, on completion.
Labeled and reviewable
AI-generated content is marked as such, references resolve to real anchors, and like / dislike / report close the feedback loop — the responsible-AI layer from the eBay work.
