AI-powered UX

Trust is an interaction pattern, not a badge

The panel on the right answers questions about this portfolio. It is a deterministic demo — no model is called — built to the conventions a Copilot-style feature needs: it streams, it can be stopped, it cites sources you can click, it says when it has none, and it labels itself.

Grounding, not a percentage
Users can act on "grounded in 2 sections" or "no source on this page"; they can't act on "confidence 71%". Shipped as confidence and explainability indicators at eBay; carried into the Apple search experience.
Refusal is a state
When the answer has no source, the panel says so and offers a next step — the same fallback logic the Apple components handle for partial and failed responses.
Streaming with a way out
Progressive rendering keeps the UI responsive under model latency; Send becomes Stop while generating; screen readers hear the answer once, when it completes, not token by token.
Labeled and reviewable
AI-generated content is marked as such, references resolve to real anchors, and like / dislike / report close the feedback loop — the responsible-AI layer from the eBay work.

Accessibility statement

Target: WCAG 2.2 AA. Below is what was actually tested on this page, and what wasn't yet. A claim that lists no test method isn't a claim.

  • ✓axe-core 4.10.2 via Playwright (Chromium, 1280×900), WCAG 2.x A/AA + best-practice rules: 0 violations in light and dark themes, specs on and off. Tested 9 Sept 2026.
  • ✓Computed contrast for every visible text element against its effective background (369 light / 368 dark): none below 4.5:1 for body text or 3:1 for large text; redline pills 5.9:1 light / 6.1:1 dark.
  • ✓Keyboard: skip link first in tab order, 36 focusable controls, theme as a native radio group, sticky-nav scroll-padding, two-tone :focus-visible ring; Escape stops generation in the demo.
  • ✓Reflow at 360 CSS px with no horizontal scroll; wide tables scroll inside their own container; disclosure targets ≥ 24 px.
  • ✓prefers-reduced-motion honored: the demo inserts the full answer at once; redline fade disabled; smooth scroll off.
  • ✓Streaming answers use role="log" + aria-busy, announced once on completion through a persistent role="status" region; answers are inserted with textContent, never innerHTML.
  • !Not yet run on this page: NVDA + Edge, JAWS, VoiceOver + Safari, Windows High Contrast (a forced-colors stylesheet ships, unverified). Known exception: the redline overlay is visual-only — its text twin is in the next card.
